# What is this Mini Django Project?

This is a website application that shows information on different BSD operating systems for example FreeBSD, OpenBSD and NetBSD.

Python and Django Version:

Python = Python 3.12.3
Django = 4.2.11

# How to install dependencies:

Open the Terminal application and run the command "pip install -r requirements.txt".

# How to apply migrations:

python3 manage.py makemigrations bsd_operating_systems
python3 manage.py migrate bsd_operating_systems

# How to run the server: 

python3 manage.py runserver

# The URL to my website page:

http://127.0.0.1:8000/bsd-os/
