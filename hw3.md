## Часть 1. Мини-проект Django

Создайте Django-проект на **свою тему** (книги, задачи, рецепты, фильмы, тренировки — что угодно, лишь бы было понятно вам).

Минимум, что должно быть:

### 1. Модель

- Хотя бы **одна** модель с **3+ полями** (не считая `id` и автоматические поля вроде `auto_now`).
- Модель зарегистрирована в **admin** (по желанию, но полезно для отладки).
- Выполнены `makemigrations` и `migrate`.

**Пример** (не копируйте слепо — придумайте своё):

```python
class Book(models.Model):
    title = models.CharField(max_length=200)
    author = models.CharField(max_length=100)
    published_year = models.PositiveIntegerField()
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.title
```

### 2. Страница со списком записей

- Хотя бы **одна** страница (view + URL + шаблон).
- На странице отображается **список объектов** вашей модели из базы (через ORM: `Model.objects.all()` или фильтр).
- Шаблон наследуется от **базового** (`base.html`) или оформлен минимально аккуратно — на ваш вкус.

### 3. Форма на `ModelForm`

- Форма объявлена как **`ModelForm`** (не обычный `Form` с ручным перечислением всех полей, если только не нужны кастомные поля).
- На **той же странице** или на отдельной — возможность **добавить** новую запись через POST.
- После успешного сохранения — редирект или сообщение об успехе (хотя бы `redirect` на список).

**Пример формы:**

```python
class BookForm(forms.ModelForm):
    class Meta:
        model = Book
        fields = ["title", "author", "published_year"]
```

**Пример view (идея, не единственный вариант):**

```python
def book_list(request):
    books = Book.objects.all()
    if request.method == "POST":
        form = BookForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect("book_list")
    else:
        form = BookForm()
    return render(request, "books/list.html", {"books": books, "form": form})
```

## Часть 2. Тема итогового проекта

Это задание на **размышление**, не на код. Оформите файл `hw3/final_project.md`.

### Что написать

1. **Название проекта** (рабочее, можно изменить позже).
2. **Для кого / зачем** — 2–4 предложения: какую задачу решает сайт.
3. **2–4 модели**, которые планируете (название + по одному предложению, что хранит).
4. **3–5 страниц / функций**, которые хотите реализовать к концу курса (список, деталь, форма добавления, поиск, личный кабинет — что актуально для вашей темы).
